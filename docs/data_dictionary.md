# Data Dictionary

| Column Name | Description | Data Type |
|------------|------------|----------|
| year | Manufacturing year of car | integer |
| make | Car brand | string |
| model | Car model | string |
| trim | Variant of car | string |
| body | Body type (SUV, Sedan, etc.) | string |
| transmission | Type of transmission | string |
| vin | Vehicle identification number | string |
| state | Location of sale | string |
| condition | Condition rating | float |
| odometer | Distance driven | float |
| color | Car color | string |
| interior | Interior color | string |
| seller | Seller name | string |
| mmr | Market price estimate | float |
| sellingprice | Actual selling price | float |
| saledate | Date of sale | datetime |
| sale_year | Extracted year | integer |
| sale_month | Extracted month | integer |
| price_difference | Selling price - MMR | float |
